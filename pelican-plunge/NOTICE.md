# Pelican Plunge

A one-thumb arcade game for iPhone, built by Muse for Better Pelicans (October 2026).

- **Play:** https://betterpelicans.com/pelican-plunge/
- **How:** Drag anywhere to steer the pelican. Catch leaping fish (gold = 50 pts),
  chain catches for combo multipliers, dodge jellyfish and storm clouds. Three hits ends the run.
- **Tech:** One self-contained `index.html` — canvas rendering, synthesized WebAudio
  sound effects, no dependencies, no tracking, no network calls. Best score is kept
  in the browser's local storage only.
